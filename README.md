# anatrevizan.com

Ana Trevizan's official website, built with Astro, TinaCMS, and TypeScript.

## Requirements

- Node.js 22.22 or later
- pnpm 11

## Getting started

```sh
pnpm install
pnpm dev
```

To validate the project:

```sh
pnpm test
pnpm exec astro check
```

Required environment variables for integrations must be configured in the runtime environment and must never be committed.

The code, text, images, logo, and other project assets are provided for inspection only and are not generally licensed for reuse.
